Exercice 1 - Style de base

  1. Le titre de l'exercice courant, puis ajoutez à la balise h2 un attribut style qui permet de mettre le titre de l'exercice en rouge brique

    <h2 style="color: brickred;">Exercice 1 - Style de base</h2>

  2. Déclarez une balise style à l'intérieur des balises head du document, puis faites en sorte que tout le document utilise une police sans-serif.

    body { font-family: sans-serif; }

  3. Faites en sorte que la balise h1 corresponde à une police de 26 points, la balise h2 à une police de 22 points et la balise h3 à une police 18 points.

    h1 { font-size: 26px; } h2 { font-size: 22px; } h3 { font-size: 18px; }

  4. Faites en sorte que le titre du compte rendu de TP soit centré.

    .centered { text-align: center; }

  5. On veut que votre nom soit aligné à droite. Commencez par déclarer votre nom entre des balises div puis ajoutez une classe right permettant d'aligner le texte à droite.

    <div class="right">Yassine HAMROUNI</div>

  6. Ajoutez un lien vers le cours http://forax.github.io/course/progweb/ puis faites en sorte que le lien soit en gras si la souris n'est pas sur le lien et en bleu-vert (teal) si la souris survole le lien.
    Conseil: Vous utiliserez pour cela les pseudo-classes des liens.

    .linkStyle { font-weight: bold; } .linkStyle:hover { font-weight: normal; color: teal; }

Exercice 2 - Style de liste et de table

  1. On veut maintenant créer une feuille de style externe, c'est-à-dire une feuille de style déclarée non pas à l'intérieur de compte-rendu-tp2.html mais dans un fichier externe nommé compte-rendu-tp2.css.
    Modifiez votre travail pour que le compte rendu utilise ce fichier de style.

    Le fichier de style est lié avec <link rel="stylesheet" href="./styles/compte-rendu-tp2.css"> dans l'en-tête du document HTML.

  2. Pour la suite du TP, nous ne modifierons plus la balise style du compte rendu mais le fichier compte-rendu-tp2.css
    Faites en sorte que la liste des questions de cet exercice et de l'exercice précédent utilise les chiffres romains (en majuscule) plutôt que les traditionnels chiffres 1, 2, 3, etc.

    ol { list-style-type: upper-roman; }

  3. Faites en sorte que la table occupe toute la largeur du compte rendu.

    .movieTable { width: 100%; }

  4. Centrez les titres et changer la police de caractères des titres pour utiliser des petites majuscules (small caps).

    .movieTable th { text-align: center; font-variant: small-caps; }

  5. Aérez la table avec la propriété padding pour que le texte ne soit pas collé aux bordures.

    .movieTable td, .movieTable th { padding: 10px; }

  6. Faites en sorte que les valeurs des deux premières colonnes (rang et titre) soient alignées à gauche et que les valeurs de la dernière colonne soient centrées.

    .movieTable th:first-child, .movieTable td:first-child, .movieTable th:nth-child(2), .movieTable td:nth-child(2) { text-align: left; } .movieTable td:last-child { text-align: center; }

  7. Changez la couleur de fond des lignes paires (even) pour mettre du bleu clair en utilisant la pseudo-classe :nth-child.

    .movieTable tr:nth-child(even) { background-color: lightblue; }

  8. Faites en sorte que si l'on survole une ligne avec la souris la couleur du fond correspond à 38 sur 255 de rouge, 24 sur 255 de vert et 44 sur 255 de bleu en utilisant un codage hexadécimal.

    .movieTable tr:hover { background-color: #26182C; }

Exercice 3 - Vignettes exo3.html

  1. Récupérez les 6 images d'animaux ainsi que le fichier exo1.html dans ce répertoire.

  2. Faites en sorte que toutes les images à l'intérieur des boîtes (pas les autres) aient une largeur (width) de 250 pixels.

    img { width: 250px; }

  3. Au lieu d'afficher les images verticalement, on souhaite les afficher horizontalement. Utilisez pour cela l'attribut float.

    body > div { float: left; }

  4. Que se passe-t-il si l'on fait varier la taille de la fenêtre du navigateur horizontalement ?

    Les boîtes flottantes peuvent se repositionner en fonction de l'espace disponible, passant potentiellement à la ligne suivante si la fenêtre est trop étroite.

  5. Vérifiez que vous pouvez aussi mettre toutes les images à droite en changeant juste un mot dans la partie CSS du document.
    Puis remettez les images alignées à gauche.

    Modifier 'float: left;' en 'float: right;' dans le CSS pour aligner à droite, puis inverser le changement pour aligner à gauche.

  6. Faites en sorte que les titres (animal1, animal2, etc.) soient affichés en blanc sur fond noir et soient centrés horizontalement par rapport à la boîte qui les contient.
    Jouez de plus avec la propriété padding pour avoir un espacement convenable.

    div > div { background-color: black; color: white; text-align: center; padding: 5px; }

Exercice 4 - Barre de menu exo4.html

  1. Faites en sorte que la liste ait une position fixe, en haut à gauche de la partie affichage du navigateur.

    div ul { position: fixed; top: 0; left: 0; }

  2. Retirez le style par défaut des items de liste (avec list-style-type) pour qu'il n'y ait pas de style par défaut.

    div ul { list-style-type: none; }

  3. Affichez les items en gras et avec une police Courrier (ou sinon serif).

    div ul li { font-weight: bold; font-family: Courier, serif; }

  4. Faites en sorte que les items soient affichés horizontalement collés à gauche et non plus verticalement.

    div ul li { display: inline-block; }

  5. Faites en sorte que les items aient une largeur de 120 pixels et ajoutez un espacement d'une dizaine de pixel entre les items.

    div ul li { width: 120px; margin-right: 10px; }

  6. Changez le fond du menu pour qu'il soit de couleur tomate (tomato), puis en chantant yellow submarine, changez la couleur des items pour qu'ils soient en jaune.

    div { background-color: tomato; } div ul li { color: yellow; }

  7. Fixez la hauteur (height) du menu à 48 pixels puis faites en sorte que le menu occupe toute la largeur (width).

    div { height: 48px; width: 100%; }

  8. Faites en sorte d'avoir un item 'Help' soit affiché à droite de la barre de menu.

    div ul li:last-child { float: right; }

  9. Affichez une ligne de 2 pixels en bas du menu.

    div { border-bottom: 2px solid black; }

Exercice 5 - Faire un sous-menu (Optionnel)

  1. Positionnez le sous-menu juste en dessous de l'item web (avec relative/absolute).

  2. Utilisez la propriété display pour ne pas afficher le sous-menu par défaut.

  3. Faites en sorte d'afficher le sous-menu si l'on passe la souris sur l'item 'Web'.

  4. L'astuce est d'avoir un sélecteur CSS qui correspond à la liste à l'intérieur de l'item Web si celui-ci est survolé par la souris et de lui appliquer la propriété display à block.

  5. N'oubliez pas de jouer avec la propriété z-index pour mettre le sous menu au-dessus du reste de la page.

  6. Vous pouvez maintenant vous amuser à rendre le menu plus beau, par exemple, en mettant une ombre portée, des coins ronds ou d'autres effets de votre choix.
