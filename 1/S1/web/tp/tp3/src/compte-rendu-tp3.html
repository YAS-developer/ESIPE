Exercice 2 - Horloges de différentes tailles

  1. Faites en sorte que la taille de l'horloge puisse varier en fonction de la taille du canvas Un canvas a une propriété width et une propriété height. Dans le cas où la largeur et la hauteur d'un canvas n'est pas la même, prenez la valeur minimum entre les deux et laisser des bandes de chaque coté.

    Le rayon de l'horloge est défini en fonction de la plus petite dimension du canvas, permettant ainsi à l'horloge de s'adapter à la taille du canvas. La ligne de code suivante assure cette adaptation :

    const radius = Math.min(canvas.width, canvas.height) * 0.85 / 2;

    Cette formule calcule le rayon comme 85% de la moitié de la plus petite dimension du canvas. Ainsi, l'horloge reste centrée et proportionnelle, quelle que soit la taille du canvas.

  2. Faites en sorte d'avoir une fonction startClock qui prend en paramètre l'id d'un canvas qui sert d'unique point d'entrée pour faire fonctionner une horloge. Testez avec l'affichage des 2 horloges de tailles différentes (on est d'accord, on peut en ajouter plus !).

    function startClock(canvasId) {
      const canvas = document.getElementById(canvasId);
      const context = canvas.getContext("2d");
      window.setInterval(() => {
       refresh(canvas, context);
      }, 1000); // Mettre à jour toutes les secondes
    };

  3. Question top moumoute, faites en sorte de garantir que les aiguilles des différentes horloges soient synchrones (i.e. misent à jour toutes en même temps).

    On cree tout d'abord une variable globale:

    let clocks = [];

    Cette derniere va permettre d'enregistrer les differentes horloges avec la fonction startClock:

    function startClock(canvasId) {
     const canvas = document.getElementById(canvasId);
     const context = canvas.getContext("2d");
     clocks.push({ canvas, context });
    }

    Ensuite on juste a appeler la startClock pour chaque horloge, et puis mettre un setInterval pour la fonction d'update qui va elle parcourir la variable clocks:

    function updateClocks() {
       clocks.forEach(({ canvas, context }) => refresh(canvas, context));
    }

    window.onload = () => {
    startClock("clock"); // Démarrez la première horloge
    startClock("clock2"); // Démarrez une deuxième horloge (si elle existe)
    window.setInterval(updateClocks, 1000);
    }
