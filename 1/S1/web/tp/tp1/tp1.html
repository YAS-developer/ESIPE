  1. Que manque-t-il comme information à la balise head pour que le fichier s'affiche correctement ?

    Tout s'affiche correctement dans Firefox. Cependant cela peut-etre different d'un moteur de recherche à un autre.
    Par consequent on metterait cela dans la balise head:
    <meta charset="UTF-8">

  2. A quoi servent les tags h1, h2 et h3 ?

    Elles servent a ecrire des titres dans une page html, plus le nombre est eleve, plus la taille de la policie est reduite.
    taille de police de h1 > taille de police de h2 > taille de police de h3.

  3. A quoi sert le tag p ?

    Il sert a ecrire un paragraphe.

  4. Ajoutez à votre compte rendu la phrase suivante :

    Les tags HTML commencent par une balise ouvrante <foo>et finissent
    par une balise fermante </foo>

  5. Comment mettre en gras ou en italique?

    Pour mettre en gras, il suffit d'utiliser la balise <b>exemple</b>. Ce qui donne: exemple
    Pour l'italique, on utilise la balise i <i>exemple</i>. Ce qui donne: exemple

  6. Et comment faire pour mettre un mot à la fois en gras et en italique ?

    On utilise dans un premier temps la balise b et a l'interieur de cette balise on y met la balise i. Ou l'inverse:
    <b><i>txt</i></b> ou <i><b>txt </b> </i>
    Ce qui donne exactement la meme chose:
    Exemple ou Exemple

  7. On souhaite que le titre de la fenêtre du navigateur soit "Compte Rendu de TP1", comment faire ?

    Il suffit d'ajouter dans la balise head:
    <title>Compte Rendu de TP1</title>

Exercice: 3

  1. On cherche à savoir à quoi correspond le fichier /etc/services.

    On y trouve des informations sur les services réseaux associés à des ports,
    notamment les noms de service et les numéros de port associés.

  2. Utilisez la commande grep sur le fichier /etc/services pour déterminer le numéro du port TCP correspondant au service http.

    Le numéro du port TCP correspondant au service http est le port 80.

    Quel est le header (l'entête, en français) de la réponse ?

    HTTP/1.0 404 Not Found

  3. A quoi correspondent les 3 valeurs sur la première ligne de l'entête ?

    les trois valeurs sur la première ligne de l'entête correspondent à:

    • La version du protocole HTTP utilisé. Ici on nous renvoie du HTTP/1.0
    • Le code de statut de la réponse. Ici on a une erreur 404. Une page internet ou une ressource non disponible.
    • Le descriptive du statut. "Not Found" ce qui est bien en lien avec le code de statut.

  4. A quoi correspond la valeur de Content-Type ?

    L'en-tête Content-Type indique le type de contenu de la réponse.
    Dans notre cas ca serait: text/html

  5. A quoi correspond la valeur de Content-Length ?

    L'en-tête Content-Length indique la longueur du contenu en octets. Dans notre cas ca serait: 345 octets

  6. Faites la même analyse, mais avec la requête
    GET / HTTP/1.1
    Host: www.example.com

    Les trois valeurs sur la première ligne de l'entête correspondent à:

    • Renvoie du HTTP/1.0
    • Le code de statut de la réponse est 200. Cela indique la réussite d'une requête
    • le descriptive de code de statut "OK" pour dire que tout c'est bien passer.

    Le Content-type est toujours du text/html mais en y ajouter le charset=UTF-8.
    Le Content-Length est de 1256 octets.

  7. Pourquoi dans la version 1.1 du protocole HTTP, on doit fournir le Host ?

    Car a partir du HTTP/1.1, les sites Web peuvent partager la même adresse IP et le même port mais ils sont distingués en fonction du nom de domaine
    spécifié dans l'en-tête Host de la requête HTTP.

    GET / HTTP/1.1
    Host: www.forax.org
