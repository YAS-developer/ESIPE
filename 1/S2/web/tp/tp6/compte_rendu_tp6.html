TP - Manipulation des Fichiers JSX et React

Compte Rendu de TP - React

Introduction

L'objectif de ce TP est d'apprendre à manipuler les fichiers JSX et à utiliser la bibliothèque React pour développer des applications web interactives. Nous allons créer une application capable d'afficher une liste de films, de supprimer des films et de filtrer l'affichage des films par les premières lettres du titre.

Installation des Bibliothèques

Pour commencer, nous devons installer les bibliothèques nécessaires et l'outil de transformation des fichiers JSX en fichiers JS.

  1. Installation d'esbuild

    npm install --save-exact --save-dev esbuild

  2. Installation de React et React-DOM

    npm install --save-exact --save-dev react react-dom

Création et Transformation des Fichiers JSX

Nous allons maintenant écrire un fichier JSX et le transpiler en JavaScript avec esbuild.

  1. Fichier HTML de Départ

    <!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8">
    <link rel="icon" href="data:,">
    <script src="exo1.js" type="text/javascript"></script>
    <style></style>
  </head>
  <body>
    <div id="App"></div>
  </body>
</html>

  2. Fichier JSX

    import * as React from 'react';
import * as ReactDOM from 'react-dom/client';

function App() {
  return <>
        <h1>Movie Database</h1>
        <div></div>
    </>;
}

window.onload = () => {
  let appDOM = document.getElementById("App");

  let root = ReactDOM.createRoot(appDOM);
  root.render(<App/>);
};

  3. Transpiler le fichier JSX en JS

    ./node_modules/.bin/esbuild exo1.jsx --bundle --outfile=exo1.js

  5. Appeler le Serveur pour Obtenir les Films

    async function fetchMovies(setMovies) {
  try {
    const response = await fetch('/api/movie');
    const movies = await response.json();
    setMovies(movies);
  } catch (error) {
    console.error('Error fetching movies:', error);
  }
}

  6. Ajouter un Bouton de Suppression

    async function deleteMovie(id, setMovies) {
  try {
    await fetch(`/api/movie/${id}`, { method: 'DELETE' });
    fetchMovies(setMovies);
  } catch (error) {
    console.error('Error deleting movie:', error);
  }
}

function MovieDelete({ id, setMovies }) {
  return <button onClick={() => deleteMovie(id, setMovies)}>X</button>;
