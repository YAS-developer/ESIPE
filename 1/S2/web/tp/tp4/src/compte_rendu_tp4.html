Exercice 1 - Treasure Map

  1. Recopiez la page Web treasure1.html. Qu'affiche le jeu sur la console ? Est-ce le résultat attendu ? Comment corriger ce problème ?

    Le jeu affiche "null" car l'élément avec l'id "game" n'est pas encore défini au moment où le script est exécuté. Pour corriger ce problème, il faut déplacer le script à la fin de la balise body ou utiliser window.onload pour s'assurer que l'élément est chargé avant d'y accéder.

  3. Expliquer pourquoi on ne peut pas utiliser la méthode forEach sur les children de game. Pour résoudre ce problème, on va utiliser Array.from().

    La méthode forEach n'est pas définie pour les HTMLCollection et NodeList, car ce ne sont pas des véritables tableaux. Array.from() convertit ces collections en tableaux, ce qui permet d'utiliser forEach.

  7. Créer les fonctions createTreasures et findTreasure et afficher le résultat de findTreasure lorsqu'un utilisateur clique sur une case.

              function createTreasures() {
            let treasures = [];
            for (let i = 0; i < 10; i++) {
              treasures.push({
                row: Math.floor(Math.random() * 8),
                col: Math.floor(Math.random() * 8)
              });
            }
            return treasures;
          }

          function findTreasure(treasures, x, y) {
            return treasures.some(t => t.row === y && t.col === x);
          }

          let treasures = createTreasures();
          Array.from(game.children).forEach((row, y) => {
            Array.from(row.children).forEach((cell, x) => {
              cell.onclick = () => {
                let hasTreasure = findTreasure(treasures, x, y);
                console.log("Cell (" + x + ", " + y + "): ", hasTreasure);
                cell.style.backgroundColor = hasTreasure ? "green" : "red";
                cell.onclick = null; // Disable further clicks
              };
            });
          });

              function createGrid(rows, cols) {
            let game = document.getElementById("game");
            for (let y = 0; y < rows; y++) {
              let row = document.createElement("div");
              row.classList.add("row");
              for (let x = 0; x < cols; x++) {
                let cell = document.createElement("div");
                cell.classList.add("cell");
                row.appendChild(cell);
              }
              game.appendChild(row);
            }
          }

  2. Créer une classe GameState pour gérer les trésors.

              class GameState {
            constructor() {
              this.treasures = this.createTreasures();
            }

            createTreasures() {
              let treasures = {};
              for (let i = 0; i < 10; i++) {
                let row = Math.floor(Math.random() * 8);
                let col = Math.floor(Math.random() * 8);
                treasures[`${row}x${col}`] = true;
              }
              return treasures;
            }

            findTreasure(x, y) {
